# Ze Simulator

Rust simulator for **Ze Theory** — quantum-information model of wave function collapse and verification of Tsirelson bound.

## Structure
- **ze-core** — physical model library
- **ze-runner** — simulation binary

## Quick start
bash
./scripts/build.sh
cargo run --release


## Parent project
**LC/Ze** — theory, axiomatics, and mathematical apparatus.

## Overview

Ze simulator — numerical simulation of the Ze (Z₂ gauge / hierarchy) model dynamics: convergence, CHSH and Born-rule tests in the Ze framework.
