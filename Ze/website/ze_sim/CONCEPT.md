# CONCEPT — Ze Simulation Website


**Type:** simulation only — see CONCEPT.md for details.
**Version:** 1.0

## What it is
Web interface for simulating the Ze model — a quantum-information theory of consciousness based on Z₂ gauge agents. Phoenix LiveView (Elixir), real-time.

## Why
Visualization and interactive exploration of Z₂ gauge agent behavior: Born rule, Tsirelson bound, agent hierarchy. Allows researchers and reviewers to "feel" the model without reading formulas.

## How it works
1. Phoenix LiveView server renders 3D/2D visualization via WebGL/Canvas
2. Model parameters (N agents, coupling strength, temperature) — via UI sliders
3. Simulation runs in real time, results update via WebSocket
4. Data export: CSV, PNG, JSON

## Context
Part of the **Ze** project (inside LC). Serves articles Ze_Model, Ze_CHSH, Ze_D, Ze-Hierarchy.

## Status
🟡 In development (Phoenix LiveView, Elixir). Focus: MVP with basic Born rule visualization.
