# Organismal Aging — CONCEPT  **Date:** 2026-06-21 **Version:** 2.0 (rewritten for Jaba's architecture) **Author:** Jaba Tqemaladze, MD — Georgia Longevity Alliance **Status:** Design (Pre-Alpha) **License:** Apache 2.0 **Codebase:** Rust + Python + Phoenix/Elixir (planned)  ---  ## 0. Purpose  **Organismal Aging** — a self-learning 4D simulator of an organism (3D + time), modeling development from zygote through ontogenesis to aging and death. Aging is considered the **root cause of all diseases** (geroscience paradigm). The simulator is integrated with the **physical robot ARGUS-LP** for automatic validation of hypotheses on physical simulators (INFOGEST, organoids, cell cultures).  **Key principles:** - **Aging is the root cause of diseases.** Not "age-associated," but "age-driven." - **Three levels:** Centriole (entropy) → MCARA counters → Tissue Ze-conflicts. - **Self-learning:** Simulator formulates a hypothesis → ARGUS-LP tests it on a physical simulator → result is fed back into the model → model is refined. - **Species universality:** Parameterizable model — from unicellular organisms to mammals. - **Openness:** Apache 2.0, open data, open hardware (ARGUS-LP).  ---  ## 1. Three Levels of the Model  ### Level #1: CENTRIOLE — Entropy Accumulator (Counter #1)  **Postulate:** The centriole is the only intracellular structure **incapable of self-renewal**. All other structures (proteins, membranes, mitochondria, DNA) are constantly renewed through synthesis/degradation. The centriole is passed on as a template during division — the old centriole always ends up in one of the daughter cells.  | Property | Centriole | All other structures | |---|---|---| | Renewal | Only replication (1×/cell cycle) | Constant synthesis/degradation | | Damage accumulation | **Yes, irreversible** | Reversible via turnover | | Entropic role | **Entropy accumulator** | Self-cleaning | | Link to aging | **Root cause** | Secondary effects |  **Mathematically:**  S_centriole(t) = S₀ + ∫₀ᵗ η(τ) dτ  where:   S_centriole(t) — centriole entropy [0,1]   S₀ — initial entropy (at birth/zygote)   η(τ) = η_div · n(τ)/n* + η_time · τ/τ* + η_ROS · ROS(τ) + η_rep · ε_rep(τ)   n(τ) — number of divisions up to time τ   n* — reference number of divisions (Hayflick)   τ* — reference time (for postmitotic cells)   ---  ### Level #2: 5 MCARA TRACKS (Counters #2–#5)  > **Note:** Counter #6 (piRNA) is excluded from v1.0.
