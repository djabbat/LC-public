# Гравитация, вращение Земли и пубертат — концептуальная связка

> **Статус:** концептуальная схема / интеллектуальный эксперимент. Эмпирических данных о влиянии частичной гравитации на сроки полового созревания **не существует**. Все цифры — математические экстраполяции, не физиологические факты.
>
> Иллюстрация: `gravity_vs_puberty.png` (в этой же папке).

## Часть 1. Гены, отвечающие за сроки пубертата

Сроки полового созревания — высоко наследуемый (h² ≈ 50–75%) полигенный признак.

### Центральные гены (гипоталамо-гипофизарная ось)
- **KISS1 / KISS1R (GPR54)** — киспептин. Ключевой «переключатель» пубертата.
- **MKRN3, DLK1** — *ингибиторы* GnRH. Потеря функции → преждевременный пубертат.
- **TAC3 / TAC3R** — нейрокинин B (модуляция GnRH).
- **GNRH1, GNRHR** — GnRH и его рецептор; **FSHB, LHB, CGA** — гонадотропины.
- **LEPTIN / LEPR** — связь жировой массы и пубертата.
- **PROKR2, FGFR1, FGF8, CHD7, KAL1, SEMA3A** — гипогонадотропный гипогонадизм (в т.ч. синдром Каллмана).
- **NR0B1 (DAX1), NR5A1 (SF1)** — развитие гонад.

### GWAS-локусы нормальной вариативности
- **LIN28B** — один из сильнейших сигналов (рост + пубертат).
- **ESR1, TMEM38B, KCNK9, GNRH1, ZNF483, TRIM66, ID4, SEC16B, BSX** — влияют на возраст менархе и BMI.

## Часть 2. Модель «гравитация → возраст пубертата»

Модель: `onset(g) = 8 + 4·e^(−4·(g−1))` (привязана: 1g → 12 лет; потолок ~8 лет при высоком g; уход за пределы при 0g).

| Гравитация | Возраст пубертата (модель) |
|---|---|
| 0g (невесомость) | ~226 лет (практически никогда) |
| 0.167g ≈ 16.7% | **~120 лет** |
| 0.16g (Луна) | ~123 года |
| 0.38g (Марс) | ~56 лет |
| 0.5g | ~38 лет |
| 1g (Земля) | 12 лет |
| 2–3g | ~8 лет (раньше, но риски) |

**Ключевой результат:** чтобы пубертат наступал в ~120 лет, нужно ≈ **0.167g** — почти лунная гравитация.

## Часть 3. Вращение Земли → «лунная» гравитация на экваторе

Физика: эффективная гравитация на экваторе = `g − ω²R` (центробежная компенсация).

| Параметр | Значение |
|---|---|
| Нужная угловая скорость | 1.137×10⁻³ рад/с |
| Во сколько быстрее текущей | **×15.6** |
| На сколько % быстрее | **+1460%** |
| Новая длина суток | **~1.54 часа (92 мин)** |
| Доля от критического предела распада | **91.7%** |

Сейчас центробежное ослабление на экваторе — всего **0.035%** от g.

**Предел стабильности:** при сутках ~84 мин (ω²R = g) объекты на экваторе перестают давить на поверхность — планета начинает разваливаться. Целевые 92 мин — это 91.7% от предела: Земля на грани разрушения.

---

## Связка (интеллектуальный эксперимент)

```
Земля вращается быстрее (×15.6, сутки ~92 мин)
        ↓
На экваторе гравитация ~0.16g («лунная»)
        ↓
По модели пубертат сдвигается к ~120 годам
        ↓
НО: планета на 91.7% у предела распада — неосуществимо в реальном мире
```

**Вывод:** теоретически лунная гравитация на Земле → «пубертат в 120 лет», но получить её можно лишь ценой вращения вплотную к пределу распада планеты. В реальности — неосуществимо без уничтожения Земли.

> ⚠️ Всё вышеизложенное — концептуальная спекуляция для научной иллюстрации, а не установленные физиологические факты.
