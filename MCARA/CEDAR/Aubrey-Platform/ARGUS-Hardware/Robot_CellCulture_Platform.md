---

## 1. Суть проекта
Робот, который работает в **закрытом боксе с климат-контролем и атмосферным контролем** (CO2/O2/влажность/температура):
- **смотрит в микроскоп** и наблюдает культуру клеток (живые клетки, time-lapse);
- **манипулирует**: капает, забирает среду, дозирует;
- **режет фемтолазером** (микрохирургия клеток/субструктур);
- **отодвигает лазерным пинцетом** (optical tweezers: удержание/перемещение клеток).

Цель — **автономный цикл «увидел → решил → манипулировал»** без рук человека. Это будущее лабораторий: воспроизводимость, масштаб, работа 24/7, без человеческого фактора.

## 2. Ключевой вывод проверки
> **Такого «робота одной коробкой под ключ» не продают.** Система собирается из готовых модулей, а главная работа — **интеграция, калибровка и софт**, не железо. Делится на уровни автоматизации.

### Уровни
- **Уровень 1** — инкубатор + микроскоп, наблюдение культуры (коммерческое, легко);
- **Уровень 2** — + автопипетирование (дозирование/забор среды по расписанию);
- **Уровень 3** — + лазеры (фемтолазерная резка и/или лазерный пинцет);
- **Уровень 4** — + автономный AI-цикл (решения без человека).

## 4. Лазеры: что запускать первым (Уровень 3)

| Критерий | **Лазерный пинцет** | **Фемтолазерная резка** |
|---|---|---|
| Действие | удержание/перемещение без контакта | резка/абляция, удаляет субструктуру |
| Инвазивность | **неинвазивный** | инвазивный (локальное повреждение) |
| Задачи | изоляция клеток, сортировка, механика | микрохирургия, удаление клетки из слоя |
| Цена | $30–100K | $50–150K |
| Сложность интеграции | ниже | выше |

**Рекомендация под longevity: начать с лазерного пинцета.**
- Изоляция отдельных клеток для долгосрочного наблюдения (вычленить «сенесцентную» клетку, следить неделями);
- Механика клетки (жёсткость) коррелирует со старением — пинцет измеряет;
- Неинвазивный, не рушит культуру; проще и дешевле в запуске.

**Фемтолазер — вторым этапом** (микрохирургия, абляция митохондрий, контролируемые повреждения).

## 5. Архитектура интеграции/софта

```
LAYER 5 · Пользователь/Данные  — HMI, протоколы, логи, база изображений, LIMS
LAYER 4 · Оркестрация          — «что делать», планирование, эскалация на API
LAYER 3 · Зрение/AI            — локальный VLM: детект, сегментация, состояние,
                                  трекинг, «вижу → целевые координаты»
LAYER 2 · Координация/Калибровка — единая система координат, трансформации,
                                  fiducials, лимиты, interlock безопасности
LAYER 1 · Устройства           — микроскоп (µManager) · Opentrons (Python API) ·
                                  фемтолазер (galvo) · лазерный пинцет
```

### Координация и калибровка
- У каждого устройства своя система координат: stage микроскопа (XYZ), наконечник пипетки (XYZ), galvo лазера (XY+фокус Z), фокус пинцета.
- **Калибровка:** шаблон с маркерами (fiducials) → affine/гомография между парами координат; авточекпоинт перед каждой сессией.
- **Поток:** AI-зрение находит цель → координаты в системе микроскопа → трансформация в координаты манипулятора → команда → подтверждение камерой (замкнутый контур).

### Стек
- Микроскоп: **µManager / Micro-Manager** (open source);
- Opentrons: официальный **Python API**;
- Зрение: **Cellpose / StarDist** + **локальный VLM**;
- Шина: Python + Redis/ZMQ.

## 6. Модели (локальная тонкая настройка + API для разметки)

### Локальный VLM / зрение (на 96GB или 2×5090)
| Задача | Модель |
|---|---|
| Сегментация клеток (стандарт) | **Cellpose** / **StarDist** |
| Vision-language «управление боксом» | **Qwen2.5-VL-7B / 32B** (fine-tune на своей карте) |
| Патология/гистология (WSI) | **UNI** (Mass General), **Virchow2** (PaigeAI) |
| Патологический VLM | **OpenPath**, **LLaVA-Med** |

### API для разметки слайдов (под бюджет)
| API | Назначение | ~Цена |
|---|---|---|
| **Gemini 2.5 Flash** ✅ | массовая/черновая разметка, дёшево | ~$0.3/M in · $2.5/M out |
| **Qwen-VL** (DashScope) | дёшево, изображения | ~$0.5–1/M |
| **Claude Sonnet 4** | сложная/точная разметка | ~$3/M in · $15/M out |
| **GPT-4o / 4.1** | надёжная разметка | ~$2.5/M in · $10/M out |

**Правило:** локальная модель — **на роботе** (реальное время, приватность, контроль железа); большая API — **для создания обучающих данных** (разметка + дистилляция). Ты обучаешь сам.
