## Суть

CEDAR — теория, согласно которой **центриоли накапливают энтропию со временем, как и все вещественные структуры.** С делениями изменяются ассоциированные с ними гипотетические структуры индукции необратимой дифференцировки (CAASM). Дополнительные нарушения структуры добавляются к энтропии центриоли случайно. **Два независимых процесса:** время → энтропия (пассивный); **асимметричные** деления → изменение CAASM (активный). Отщепление индуктора необратимой дифференцировки — только при асимметричных делениях.

### Ключевые компоненты (C1/C2)
- **C1:** Уровень polyGlu (GT335) на центриоли коррелирует с числом делений
- **C2:** Материнская центриоль асимметрично наследуется (Ninein+ остаётся в стволовой клетке)

### Правило девяти механизмов центриоль-зависимых повреждений (Jaba Tqemaladze's Rule, v5.6)

Накопление повреждений в центриоли (D_c) вызывает 9 механизмов патологии:

**Core (M1-M3):**
- **M1 — Хромосомная сегрегация:** дефекты веретена → геномная нестабильность
- **M2 — Цилиарный сигналинг:** центриоль → базальное тельце → нарушение цилии → сбой Hh/Wnt/TGF-β
- **M3 — CAASM:** 🟡→🟢 UPGRADED. центросома как платформа: Oct4 на центросоме (PMID: 41725553), CEP170→нейрогенез (PMID: 41888776), LGALS3BP→митохондрии (PMID: 42055624), PCM1→судьба клеток (PMID: 41315244), NuSAP→целостность (PMID: 41616107), цилия→TGF-β (PMID: 42233350, 41310849)

**Extended (M4-M9):**
- **M4 — MT-массивы → сенесценция:** ядро-цилия микротрубочки → KIFC3 → инициация сенесценции (Robichaud 2024)
- **M5 — Центросомная амплификация → полиплоидия → сенесценция/рак**
- **M6 — Потеря полярности → симметричные деления → истощение СК** (Bener/Inaba 2026)
- **M7 — Центросомный протеостаз** (McLendon 2025)
- **M8 — Нарушение нейрогенеза** (микроцефальные гены asp/Sas4)
- **M9 — Ооцитное/мейотическое старение** → анеуплоидия (Delimitreva 2025)

### 🔥 Ключевая находка: CD8+ T cell mother centrosome (Cell Reports 2025)

**Barandun N, Meier B, Stehli G, Gräbnitz F, Zangger N, Oxenius A** — *Targeted localization of the mother centrosome in CD8+ T cells undergoing asymmetric cell division promotes memory formation* — **Cell Reports** (2025).

**Шесть ключевых фактов:**
1. Материнская центросома ЦЕЛЕНАПРАВЛЕННО (не случайно) локализуется в одной из дочерних клеток
2. Дочерняя клетка, получившая материнскую центросому → становится клеткой ПАМЯТИ
3. Дочерняя клетка без материнской центросомы → становится эффекторной
4. Это показано в CD8+ T-клетках МЛЕКОПИТАЮЩИХ (не Drosophila, не C. elegans)
5. Родственная статья в **Nature** (2024): Fate induction in CD8 CAR T cells through asymmetric division — DOI: `10.1038/s41586-024-07862-7`
6. **Вывод:** Центросомная асимметрия → судьба клетки — УНИВЕРСАЛЬНЫЙ ПРИНЦИП (СК + иммунные клетки)

**Значение для CEDAR:** C2 повышается с 8.5 → **9/10.** M3 повышается с 6 → **7/10.**

### 🔥 Ключевая находка: Senescence ≠ telomere length (iScience 2026)

### Ключевые выводы Park/Di Stefano для CEDAR:

1. **5 уровней stem cell exit** — центриольный счётчик CEDAR находится на стыке уровней: центриоль → сигналинг → хроматин → судьба
2. **Pol II паузинг** — накопление Pol II на генах lineage specification → «быстрый ответ» — альтернативный механизм commitment
3. **Tfe3/Folliculin** — «контроль локализации TF вместо экспрессии» — 🔥 прямая аналогия с асимметричным наследованием центросом (не уровень белка важен, а его ЛОКАЛИЗАЦИЯ)
4. **Dux/Duxbl toggle** — модель switch для CAASM: как один фактор меняет судьбу (аналогия: polyGlu на центриоли как переключатель)
5. **«Точка невозврата»** — если существует, CEDAR должен её объяснить через накопление центриольных повреждений
