## Key findings (из абстракта Cell)

1. **PEtracer** — непрерывная установка наследуемых генетических меток по мере развития.
2. Реконструкция **lineage trees, разрешающих ~75% клеточных делений** по **>1,4 млн клеток из 16 репликатных эмбрионов** (собирались с полу-дневными интервалами от E7.5 до E10.0).
3. Деревья сопряжены с **глубоким транскрипционным профилированием** для разрешения судеб клеток.
4. **Цель:** карта клеточных судеб млекопитающего — «landscape of cell fate decisions» (осталась недостижимой из-за масштаба, разнообразия и недетерминированности развития in utero).

## Значение для CDLT

- **16 эмбрионов / ~75% делений** — статистическая мощность на уровне целого эмбриона; прецедент для Power Analysis CDLT (реконструкция при неполном покрытии делений возможна).
- **E7.5–E10.0** — органо-спецификация; PEtracer пригоден для этапа, где CDLT-предсказания (дифференцировка по линии) наиболее тестируемы.
- **Сопряжение lineage + транскриптом** — шаблон для того, как CDLT будет сопрягать lineage + центриолярные маркеры (GT335, Ninein).

## Слабые места (мета-анализ)

- **~75% делений** — неполнота покрытия; ~25% ветвей не разрешены (молчаливые деления, потери меток).
- Окно E7.5–E10.0 покрывает **не весь** путь от зиготы (в отличие от Shendure/Science: зигота→поздний органогенез).
- **Два метода (PEtracer vs DNA Typewriter) и два окна не пересекаются напрямую** — прямое кросс-сравнение требует отдельной работы.
- Молекулярные метки не несут информации о структуре/повреждениях центриолей.
