## Релевантность для CellLineageTree
- ⭐⭐ **Асимметричное деление НСК** (Drosophila): большая самообновляющаяся СК + меньший дифференцирующийся сиблинг — прямое lineage-деление.
- Orb2 → Polo → PCM: трансляционный контроль асимметрии центросом; асимметричное наследование структурных компонентов при делении.
- Контр-нюанс: при потере Orb2 НСК всё равно делятся асимметрично → асимметрия PCM не достаточна для асимметрии деления (для lineage-моделей: судьба ≠ жёстко закодирована центросомной асимметрией).
- Каскадная асимметрия: линия НСК → ганглиозные материнские клетки → нейроны — пример траектории асимметричных делений (ср. Junyent 2024, PMID 38744282).
