# Карта накопления необратимой энтропии в организме

## Jaba Tqemaladze · AEON Workshop, Cologne · 31 Aug – 2 Sep 2026

---

## Организм как термодинамическая система

Организм — открытая система. Поток энергии (пища, дыхание) поддерживает порядок. Но **необратимая энтропия** накапливается в структурах, которые либо (а) не обновляются, либо (б) обновляются через репликацию, **копирующую накопленные дефекты**.

### Где и в чём накапливается необратимая энтропия: полная инвентаризация

#### По локализациям

| Орган/Ткань | Накопленный субстрат | Тип необратимого повреждения | Почему не удаляется |
|-------------|---------------------|-----------------------------|---------------------|
| **Хрусталик** | Кристаллины (α, β, γ) | Дезамидирование Asn/Gln, рацемизация Asp (D-аминокислоты), изомеризация, карбонилирование, AGE-сшивки, усечение | Фиброзные клетки хрусталика теряют органеллы при созревании — нет протеасомы, нет аутофагии. Кристаллины синтезируются эмбрионально и НЕ обновляются |
| **Сетчатка (RPE)** | Липофусцин: A2E, iso-A2E (бисретиноиды) | Ковалентные аддукты ретиналя с фосфатидилэтаноламином. Фототоксичны: при 430 нм → АФК → повреждение лизосом и мембран | A2E — побочный продукт зрительного цикла. Не субстрат ни для одной известной гидролазы. Накапливается в лизосомах RPE с рождения |
| **Нейроны** | Липофусцин, агрегаты белков (tau, Aβ, α-synuclein, TDP-43), окисленные липиды (4-HNE, MDA), ядерные поры (NPC-белки: Nup107, Nup205) | Карбонилирование, дезамидирование, окислительное сшивание, агрегация. Липофусцин ингибирует протеасому (20S + 26S) и лизосомальные протеазы (катепсины B/D/L) | Постмитотические — не разбавляются делением. NPC-белки в нейронах имеют t½ > года. Липофусцин не экзоцитируется, не деградируется ни одним известным путём |
| **Миелин** | Белки миелина: PLP (протеолипидный белок), MBP (основный белок миелина), CNPase | Дезамидирование, изомеризация, карбонилирование, AGE-сшивки. MBP деамидируется с t½ ~60–70 дней у человека в белом веществе | Олигодендроциты постмитотические. Turnover миелиновых белков крайне медленный. PLP — один из самых долгоживущих белков организма |
| **Сосуды (артерии)** | Эластин, коллаген типа I/III в медии | AGE-сшивки (glucosepane), кальцификация на эластине, фрагментация эластиновых волокон, окисление | Эластин синтезируется в раннем развитии. t½ эластина у человека ~70 лет. Нет физиологического механизма удаления glucosepane |
| **Сердце (кардиомиоциты)** | Липофусцин, агрегаты десмина, окисленные митохондриальные белки | Карбонилирование, перекисное окисление липидов (4-HNE-аддукты на комплексах ЭТЦ), липофусциноз | Постмитотические с рождения. Липофусцин занимает 0.6% объёма / декаду, достигая 6–8% к 90 годам |
| **Кожа** | Коллаген типа I/III (дерма), эластин | AGE-сшивки (glucosepane — основной в коже), фотоокисление (УФ), фрагментация. Пентозидин растёт линейно c 20 лет | Коллаген кожи: t½ ~15 лет. Elastin: t½ > 70 лет (как в сосудах). Glucosepane — необратимая ковалентная сшивка Lys-Arg |
| **Почки** | Коллаген типа IV (базальная мембрана клубочков), мезангиальный матрикс | AGE-сшивки, окисленные липопротеины (в мезангии), карбонилирование | Почечный клиренс AGEs ограничен. Мезангий накапливает модифицированные белки плазмы |
| **Хрящи/суставы** | Коллаген II, агрекан | AGE-сшивки (пентозидин, CML), фрагментация агрекана металлопротеиназами, окисление | Хондроциты не делятся во взрослом хряще. t½ коллагена II может превышать 100 лет. Нет васкуляризации — ограниченный доступ репаративных клеток |
| **Кости** | Коллаген I (остеоид), гидроксиапатит | AGE-сшивки коллагена, микроповреждения (microcracks), накопление остеоцитарного апоптоза | Кость ремоделируется, но ремоделирование замедляется с возрастом. Микроповреждения ,накапливающиеся быстрее репарации |
| **Зубы (дентин)** | Коллаген I, фосфопротеины дентина | Рацемизация аспарагиновой кислоты (L-Asp → D-Asp), AGE-сшивки | Дентин не ремоделируется после формирования. Рацемизация Asp используется в судебной медицине для определения возраста |
| **Кроветворная система** | Центриоли в HSCs (гемопоэтические стволовые клетки) | PolyE на материнской центриоли, удлинение (45%→76% от 24 до 67 лет), окислительные повреждения | Консервативная дупликация центриоли. Нет репарации структурных белков центриолярной стенки |
| **Репродуктивная система** | Ооциты (женские — запас с рождения) | Мутации мтДНК, повреждения веретена деления, окислительные модификации | Ооциты не обновляются. Запас сформирован до рождения. Cohesin-белки (Rec8) не заменяются → анеуплоидия с возрастом матери |
| **Слуховой аппарат** | Волосковые клетки улитки (кортиев орган) | Окислительные повреждения, митохондриальные мутации, потеря стереоцилий | Волосковые клетки не регенерируют у млекопитающих. Потеря 1 волосковой клетки — необратима |

## Пять счётчиков необратимой энтропии

> В MCARA (Tqemaladze, 2026) — 5 счётчиков: C1 (polyE), C2 (эпигенетика), C3 (митохондрии), C4 (структура центриоли), C5 (теломеры). Здесь **C1 и C4 объединены в S₁** — одно и то же (структурный счётчик C4 следует за молекулярным C1). Реально независимых — 4, но S₄ (протеостаз) выходит за рамки MCARA (не репликативный, а организменный). Итого: 5 счётчиков необратимой энтропии организма.

### S₁ — Центриолярная энтропия (счётчик клеточных делений)

| Параметр | Значение |
|----------|----------|
| **Локус** | Материнская центриоль стволовых и прогениторных клеток |
| **Что накапливается** | **Первично (энтропия):** окислительные модификации (карбонилирование, 4-HNE-аддукты), дезамидирование тубулинов, нарушения 9×3 архитектуры, удлинение. **Вторично (одометр):** полиглутамилирование (polyE) — не причина, а маркер «пробега» центриоли |
| **Почему необратимо** | Консервативная дупликация: материнская центриоль — шаблон, не разбавляется. Нет репарации структурных белков. **Дополнительный механизм:** TRiC/CCT-шаперонин фолдит тубулин для сборки центриолей; с возрастом HSF1↓ → TRiC↓ → ошибки folding → центриоли собираются с дефектами → энтропия растёт быстрее |
| **Скорость** | ~1 ед. polyE / деление; удлинение 45%→76% от 24 до 67 лет (Köhrer et al., *Leukemia* 2023) |
| **Порог** | Сигмоида: медленно до ~60–70% повреждённых центриолей → резкое падение репликативной способности |
| **Измерение** | **Энтропия:** масс-спектрометрия (карбонилирование, дезамидирование), STED/электронная томография. **Одометр:** GT335 (anti-polyE) |
| **Обратимость** | **Необратимо.** CCP-деглутамилазы убирают polyE (одометр), но не окислительные повреждения. Полная элиминация — только Polo-киназа + деградация PCM (механизм ооцитов) |

> ⚠️ **PolyE — одометр, не энтропия.** Реальная энтропия — окислительные модификации и дезамидирование. PolyE — ферментативная модификация (TTLL/CCP), обратимая, коррелирует с возрастом центриоли. Удобный прокси, но не причина остановки.
>
> 🔬 **PolyE + протеомика:** масс-спектрометрия количественно измеряет polyE на конкретных остатках Glu-хвостов α/β-тубулина, различает моно-/ди-/полиглутамилирование, и — критически — позволяет **одновременно** с одного образца измерить и polyE (одометр), и карбонилирование/дезамидирование (реальную энтропию). Один протеомный прогон → две метрики. GT335 хорош для сортировки клеток; масс-спектрометрия — для доказательства.

### S₂ — Эпигенетическая энтропия (информационный дрейф)

| Параметр | Значение |
|----------|----------|
| **Локус** | Метилом ~28M CpG-сайтов |
| **Что накапливается** | Стохастический дрейф метилирования: гиперметилирование tumour-suppressor промоторов, гипометилирование повторов, SA-DNAm |
| **Почему необратимо** | DNMT1 fidelity < 100% при репликации; спонтанное дезаминирование 5mC→T; нет возврата к «молодому» метилому без репрограммирования |
| **Скорость** | ~1 год эпигенетического возраста / календарный год. Гипоксия замедляет на 30–40%, но не останавливает |
| **Порог** | SA-DNAm сигнатура: 6 CpG → критический порог → p16/p21 → сенесценс |
| **Измерение** | Illumina EPIC arrays (850K CpG), Horvath clock, Epigenetic-Senescence-Signature |
| **Обратимость** | **Условно обратимо.** OSKM-репрограммирование сбрасывает метилом до плюрипотентного состояния. *In vivo* — неполное, риск тератом |

### S₃ — Митохондриальная энтропия (энергетическая деградация)

| Параметр | Значение |
|----------|----------|
| **Локус** | мтДНК, внутренняя мембрана, комплексы ЭТЦ |
| **Что накапливается** | Мутации мтДНК (общая делеция 4977 bp), окисленные кардиолипины, карбонилированные субъединицы комплексов I/IV, повреждённые Fe-S кластеры |
| **Почему необратимо** | мтДНК без гистонов, репарация ограничена (нет NER), полимераза γ ошибается чаще ядерной. Порог Хартмана: 60–90% мутантной мтДНК → биохимический дефект |
| **Скорость** | Общая делеция: ~0.1% → 3–5% мтДНК в мозге/мышцах к 80 годам |
| **Порог** | 60–90% мутантной мтДНК → падение Δψm → дефицит АТФ → апоптоз/сенесценс |
| **Измерение** | Long-range PCR (делеции), NGS мтДНК (гетероплазмия), Seahorse (OCR/ECAR), TMRM (Δψm) |
| **Обратимость** | **Частично.** Митофагия удаляет повреждённые митохондрии; биогенез (PGC-1α) создаёт новые. Но мутантная мтДНК клонально размножается, обходя митофагию |

### S₄ — Протеостазная энтропия (молекулярный мусор)

| Параметр | Значение |
|----------|----------|
| **Локус** | Цитоплазма, ядро, внеклеточный матрикс |
| **Что накапливается** | **Внутриклеточно:** агрегированные белки (убиквитин⁺, p62), липофусцин, окисленные белки. **Внеклеточно:** AGE-сшивки коллагена (glucosepane), эластина |
| **Почему необратимо** | Липофусцин не деградируется — ингибирует протеасому и лизосомы. Glucosepane — ковалентные сшивки с t½ > десятилетий. Шаперонная сеть истощается с возрастом |
| **Скорость** | Липофусцин: ~0.6% объёма клетки / декада (кардиомиоциты). AGEs: линейно с ~20 лет в коже/артериях |
| **Порог** | 30–40% объёма липофусцина → лизосомальный блок → аутофагический коллапс → каскадная протеостазная катастрофа |
| **Измерение** | Аутофлуоресценция (липофусцин: ex 360/em 540), ELISA пентозидина/глюкосепана (AGEs), LC3-II/p62 (аутофагический поток) |
| **Обратимость** | **Внеклеточно — необратимо** (нет механизма расщепления glucosepane; ALT-711 спорен). **Внутриклеточно — частично** (аутофагия справляется при низкой нагрузке) |

### S₅ — Теломерная энтропия (концевая недорепликация)

| Параметр | Значение |
|----------|----------|
| **Локус** | Теломеры (TTAGGG повторы на концах хромосом) |
| **Что накапливается** | Укорочение теломер (end-replication problem); TAF (telomere-associated foci); t-циклы |
| **Почему необратимо** | ДНК-полимераза не достраивает 5'-конец lagging strand: 50–200 bp/деление. Окислительные повреждения: 1 SSB в теломере = 500 bp единовременной потери |
| **Скорость** | ~30–50 bp/деление (фибробласты); ~30–80 bp/год (лейкоциты *in vivo*) |
| **Порог** | Критическая длина ~5 kb → депротекция shelterin → ATM/ATR → сенесценс/апоптоз |
| **Измерение** | Flow-FISH, qPCR (T/S ratio), Southern blot (TRF), STELA |
| **Обратимость** | **Обратимо** через теломеразу (hTERT) или ALT. Но *in vivo* большинство соматических клеток теломеразу не экспрессируют → для них необратимо |

## Полная классификация счётчиков клеточных делений (литература + MCARA)

Ниже — все известные механизмы, counting cell divisions. MCARA (Tqemaladze, 2026) — единственная работа, которая сводит их в единую архитектуру и добавляет центриолярный счётчик.

| Счётчик | Механизм | Кто предложил | Статус | Защищён hTERT+2%O₂? |
|---------|----------|--------------|--------|:---:|
| **Centriolar** *(polyE + структурный — C1 и C4 из MCARA объединены)* | PolyE на материнской центриоли + окислительные модификации + нарушения архитектуры + удлинение | Tqemaladze (2005, 2010, 2023); Köhrer et al. (2023) — 1386 центриолей, удлинение 45%→76% | ❌ **Наш.** Ни у кого больше нет | ❌ Нет |
| **Epigenetic** | SA-DNAm: метилирование CpG (6 CpG сигнатура). Репликативный компонент часов Хорвата | Horvath (2013) — pan-tissue clock; Wagner/Koch (2013) — SA-DNAm; Kabacik/Horvath/Raj (2018) — hTERT не останавливает | ✅ Стандарт | ~ Замедлен 30–40% |
| **Mitochondrial** | Мутации мтДНК, ROS, падение Δψm, окислительные повреждения комплексов ЭТЦ | Passos/von Zglinicki; López-Otín (2023) — mitochondrial dysfunction hallmark | ✅ Стандарт | ✅ Да |
| **Telomeric** | Потеря 50–200 bp/деление (end-replication). Stress-dependent shortening | Counter CM (1996) — «telomeric DNA as mitotic clock»; von Zglinicki (2003) — «telomeres: major clock, stress sensor» | ✅ Стандарт | ✅ Да |

### Что НЕ является счётчиком делений:

| Кандидат | Почему не счётчик |
|----------|-------------------|
| **DNA damage foci / TIF** | Passanisi & Spencer (2026): на single-cell уровне НЕ предсказывает сенесценс. Downstream-эффект, а не independent counter |
| **Клеточный размер** | Разные дифференцированные клетки — разного размера (нейрон 100 мкм vs лимфоцит 7 мкм). Размер задан типом клетки, не числом делений |
| **p16/p21-pRb** | Интегратор сигналов от счётчиков → cell cycle arrest. Не считает деления сам |
| **p53-p21** | Интегратор DNA damage + теломерной дисфункции. Не считает деления сам |
| **Протеостаз (липофусцин, AGEs)** | Копится в постмитотических тканях (нейроны, сердце) без делений. Счётчик времени, не митозов |

### Ключевые выводы из литературы:

1. **До MCARA никто не предлагал центриолярный счётчик.** Counter (1996) — теломеры единственный. von Zglinicki (2003) — теломеры + DNA damage. López-Otín (2023) — 12 hallmarks, но не «счётчики делений», а «признаки старения».
2. **Passanisi & Spencer (2026)** — на уровне одиночных клеток теломеры НЕ предсказывают сенесценс. Это ослабляет Telomeric как rate-limiting.
3. **DNA damage foci (TIF)** — опровергнут как независимый счётчик.
4. **Центриолярный счётчик — единственный без защиты.** Telomeric чинит теломераза, Mitochondrial — митофагия, Epigenetic — OSKM. Centriolar не чинит никто.

| Критерий | S₁ Центриоль | S₂ Эпигеном | S₃ мтДНК | S₄ Протеостаз | S₅ Теломеры |
|----------|:---:|:---:|:---:|:---:|:---:|
| Нет физиологического механизма удаления | ✅ | — | — | ✅ (AGEs, липофусцин) | — |
| Ковалентные модификации без репарации | ✅ (окисление) | — | ✅ (мутации) | ✅ (AGE-сшивки) | — |
| Репликация копирует повреждения | ✅ (template) | ✅ (DNMT1) | ✅ (pol γ) | — | ✅ (end-repl.) |
| Механизм сброса существует, но не *in vivo* | ✅ (ооциты) | ✅ (OSKM) | ✅ (митофагия) | — | ✅ (теломераза) |

## Ключевое следствие

Пять счётчиков работают **параллельно и независимо**. Система останавливается, когда **первый** достигает порога:

1. **Разные ткани стареют с разной скоростью** — разный набор активных счётчиков (постмитотические нейроны: только S₃ и S₄; кожа и кишечник: все 5)
2. **Интервенция против одного счётчика не остановит старение** — переведёт гонку на следующий (hTERT спасает от S₅, но S₁ или S₂ остановят клетку позже)
3. **Полный сброс требует сброса всех 5** — именно это делает оплодотворение
4. **Частичное репрограммирование in vivo = частичное омоложение** — сбрасывает S₂, но S₁, S₃ и S₄ остаются

## 🔬 ВСПОМОГАТЕЛЬНЫЙ ЭКСПЕРИМЕНТ: ЗАГАДКА BODNAR 1998

```
╔══════════════════════════════════════════════════════════════════════╗
║  Почему BJ-hTERT при 21% O₂ иммортализованы?                         ║
║  Гипотеза: клональная селекция — выживают только клетки              ║
║  с молодыми центриолями                                              ║
╚══════════════════════════════════════════════════════════════════════╝
```

**Контекст:** Bodnar et al. (1998, *Science*) — BJ-hTERT при 21% O₂ делятся 300+ PD. Это стандартная интерпретация: теломераза = иммортализация. Но при 2% O₂ та же линия проходит кризис (MacKenzie 2000; Franco 2001). **Aubrey de Grey указал на этот зазор как на ключевой экспериментальный пробел в модели (личная дискуссия, июнь 2026).**

**Гипотеза:** при 21% O₂ клетки со старыми центриолями (высокая энтропия) достигают предела Хейфлика и гибнут. Выживают только клоны с аномально молодыми центриолями. Bodnar видел не отмену предела, а **клональную селекцию**.

| # | Шаг | Метод | Что измеряем |
|---|-----|-------|-------------|
| **1** | **Разделить популяцию** | BJ-hTERT, 21% O₂. Сортировка по polyE (GT335) + длина центриоли → «молодые» vs «старые» | Распределение: % клеток со старыми центриолями? |
| **2** | **Клональный трекинг** | Клоны из одиночных клеток с молодыми vs старыми центриолями. Считать PD до ареста | Достигают ли «старые» клоны предела Хейфлика? |
| **3** | **Измерение реальной энтропии** | Масс-спектрометрия: карбонилирование, дезамидирование. **Не polyE — реальные повреждения** | Коррелирует ли одометр (polyE) с энтропией? |
| **4** | **Контроль: 2% O₂** | Та же схема при 2% O₂ — где нет клональной селекции | При 2% O₂ старые центриоли накапливаются равномерно? |

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│   ПРЕДСКАЗАНИЕ:                                                     │
│                                                                     │
│   21% O₂: клоны со СТАРЫМИ центриолями → предел Хейфлика → гибель. │
│           Выживают только клоны с МОЛОДЫМИ центриолями.             │
│                                                                     │
│   2% O₂: старые центриоли накапливаются равномерно во всей          │
│           популяции → вся популяция достигает предела.              │
│                                                                     │
│   Если ДА  → Иммортализация Bodnar — артефакт клональной селекции.  │
│              Клетки со старыми центриолями умирают, молодые          │
│              размножаются. Предел Хейфлика реален для всех.          │
│                                                                     │
│   Если НЕТ → S₁ не rate-limiting при 21% O₂. Иммортализация         │
│              реальна. Нужен другой механизм.                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

> ⚠️ **PolyE — одометр, не энтропия.** Сортировка по polyE допустима как прокси, но доказательство требует прямого измерения карбонилирования и дезамидирования масс-спектрометрией.
