## 1. Что даёт ARGUS сам (фаза 1 — платформа)

Покрыто BOM (~$10,900): OpenFlexure + инвертированный микроскоп высокого разрешения (OS4) + sCMOS + лазеры/гальво + инкубатор + Hailo-8L AI + микроманипуляторы.

**Фаза 2 = биологическая валидация LERR-треков** → здесь нужна внешняя лабораторная инфраструктура.

## 2. Оборудование по приоритету

### 🟥 Must-have в своей лаборатории

| Аппарат | Для чего (трек LERR) | Ориентир |
|---|---|---|
| **Гипоксический CO₂-инкубатор (3% O₂)** | Культура P5 vs P25, кислородный парадокс (Phase 0); базовая клеточная работа | ~$3–6K |
| **Ламинарный бокс BSL-2** | Культура + лентивирусная трансдукция (BJ-hTERT для ARGUS, BSL-2) | ~$3–5K |
| **Инвертированный флуоресцентный микроскоп + live imaging (time-lapse, инкубаторный)** | R4 — качество делений зиготы, live imaging; дублирует/калибрует ARGUS | ~$20–40K или доступ |
| **Флуоресцентный микроскоп + U-ExM-стек** | M1–M5 структурные метрики (триплеты, SDA-кольцо, GT335) | ~$15–30K (или конфокал) |
| **FACS-сортировщик** | Сортировка HSC (LSK), отбор наименее повреждённого пула (Ladder-шаг 1), сортировка по низкому Δ2/polyGlu | ~$50–120K или ЦКП-доступ |
| **Ультрацентрифуга (сахарозный градиент)** | Изоляция центросом (Эксп. 2): sucrose gradient + salt-strip (1M KCl) | ~$15–30K |
| **Базовый набор мол. биологии** | WB (GT335/LC3B/p62), PCR, CRISPR (CCP1-KO, POC1A/B-KD), SA-β-Gal, γ-H2AX, Annexin V | ~$10–20K |

### 🟨 Желательно / партнёрский доступ (не покупать сразу)

| Аппарат | Для чего | Комментарий |
|---|---|---|
| **STED / суперрезолюция** | Точные центриолярные измерения (R1, R3) | Дорого (~$500K+) → CECAD/Guichard, часы |
| **cryo-ET** | Верификация структуры (R3) | Только внешний доступ |
| **Масс-спектрометр (Orbitrap-класс)** | SILAC (оборот скаффолда), центросомный IP-MS (TMT), редокс-протеомика | ~$400K+ → CECAD (Meyer), Кёльн |
| **КРС-IVF/IVM + эмбрио-инкубатор** | Эксперимент 4 (отцовская центриолярная энтропия) | Нужен партнёр (внешний) |
| **Виварий (C57BL/6, облучатель)** | Эксперименты 1–2 (мыши, трансплантация) | Партнёрский виварий |

## 3. Ключевой вывод для ответа Алексею

Минимально «точно необходимо» в своей лаборатории для фаз 1–2 ARGUS:

1. **Гипоксический CO₂-инкубатор + ламинар BSL-2** — фундамент культуры фибробластов (без этого ничего).
2. **Инвертированный флуоресцентный микроскоп с живой съёмкой** — дублирует ARGUS, нужен для валидации и эмбрио-части.
3. **U-ExM-стек + флуоресцентный микроскоп** — главный валидационный readout CEDAR (M1–M5).
4. **FACS** — Ladder-шаг 1: отбор наименее повреждённого пула (можно через ЦКП).
5. **Ультрацентрифуга + WB-набор** — центросомная биохимия.

STED, cryo-ET, MS и IVF — **не покупать**, а брать часами/по партнёрству (контакты Meyer/CECAD, Guichard уже установлены — заложено в бюджеты заявок).
