## 2. Слабые места протокола (обязательные разделы для ревизии)

1. **Ренцова-парадокс (30197118).** Элиминация центриолей в hPSC → p53-зависимая дифференцировка. Требует gatekeeper-эксперимента (PLK4-ингибиция + PFT-α + PIDDosome-ингибитор + DUX4/TPRX1 → MERVL⁺), иначе фаза 2 несостоятельна.
2. **Планарии (25047607).** Ацентриолярные необласты плюрипотентны, но не тотипотентны → элиминация сама по себе недостаточна; нужны факторы (подтверждает трёхфазность, опровергает «только Eliminate»).
3. **p53-арест в соматических клетках.** Центрин → G1-арест в диплоидных фибробластах (25931445); 53BP1–USP28–p53–p21 (27432897/27371829/27432896). Без p53-блокады Eliminate = арест; с блокадой — окно геномной нестабильности → кариотип на каждом пассаже.
4. **PLK4-амплификация (40257113; 41453690; 41749477; 41644695).** Rebuild-титрование критично; новые «тормоза» (FBXW7, McIdas) — кандидаты для встроенного контроля.
5. **DUX4-токсичность (FSHD).** Снижать дозу через KLF18 (41986233) / Obox4 (38856708) поддержку сети; обязателен Tet-On + kill-switch.
6. **8CLC транзиентны + промежуточные состояния** (TPRX1 без LEUTX): endpoint (CTI/ZGA-панель) должен различать полную и частичную программу, иначе ложноположительные «тотипотентные» сигналы.
