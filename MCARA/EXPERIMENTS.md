# MCARA - EXPERIMENTS: Centriole Elimination + OSKM → iPSC

**Дата:** 2026-07-09 | **Версия:** v1.1
**Контекст:** Каталог возможных исходов центрального эксперимента CEDAR.

> ⚠️ **ВАЖНО: Для лучшей воспроизводимости в основной статье описана только часть возможных экспериментов.** Представленные здесь 29+ исходов - это ПОЛНЫЙ каталог. Реальный воспроизводимый дизайн фокусируется на 3 методах, 1-2 клеточных линиях и 2 временны́х окнах. Общее количество возможных комбинаций (метод × линия × время × ингибитор) превышает 200.

## ГЛАВНАЯ ГИПОТЕЗА (ДВУНАПРАВЛЕННАЯ)

**Оригинальный CEDAR-прогноз:** Элиминация центриолей → снятие барьера → **увеличение** эффективности репрограммирования.

**Альтернативный прогноз (Renzova 2018):** Центриоли необходимы для плюрипотентности → их потеря → **снижение** эффективности.

Оба исхода одинаково информативны.
