## 3. ПОВОРОТНЫЙ МОМЕНТ — МИНУТЫ 3–7

> *После твоего ответа Jacks либо зацепится за что-то конкретное, либо задаст общий вопрос. Вот вероятные сценарии:*

### Сценарий А: «Tell me more about the experiment»

Расскажи CEDAR experiment — коротко:

> *«Take human fibroblasts. Eliminate centrioles — chemically with centrinone, or physically with a laser. Then add DUX4 to push toward totipotency. Then let the cell assemble new centrioles de novo to lock in the new state. Eliminate, reprogram, rebuild. If my hypothesis is right, reprogramming efficiency goes up at least 2x, because you removed the hardware lock. If it goes down, I'm wrong, and we learn that centrioles are needed for reprogramming. Either result is informative. Nobody has done this experiment. Sixty verified PMIDs — nothing. It's a three-year, three-million-euro project. Testable. Falsifiable.»*

### Сценарий Б: «How does this connect to Hameroff's work?»

> *«Stuart's insight — and I think it's profound — is that a microtubule is not just a structural polymer. The tubulin dimer has an electric dipole. Polyglutamylation adds negative charges — it changes the dipole. If microtubules are quantum computers as Stuart argues, then the tubulin code — the pattern of PTMs — directly modulates the computation. What we see in aging is a progressive change in that code. The centriole, with its nine triplet microtubules, is the most stable microtubule structure in the cell. If anywhere, that's where accumulated PTM changes would matter most.»*

### Сценарий В: «What's the Bandyopadhyay connection?»

> *«Anirban measures individual microtubules with a scanning tunneling microscope — he gets resonance frequencies in gigahertz. Nobody has ever measured a centriolar microtubule that way. A centriole is nine triplets — a very different geometry from a cytoplasmic microtubule. If his fractal model applies, a centriole should have its own resonance signature. And if polyglutamylation changes the charge distribution, it should shift that signature with age. That's a direct, testable prediction.»*

### Сценарий Г: «So you think aging is a microtubule problem?»

> *«Aging is many problems. But one of them — and I think the one that limits stem cell renewal — is centriolar. The centriole has no repair mechanism. Every other structure in the cell — DNA, proteins, membranes — has quality control. The centriole doesn't. If it gets damaged, the cell's only option is to eliminate it and build a new one de novo. That's what happens in the zygote. In stem cells, asymmetric division keeps the old centriole in the stem cell lineage. Over decades, entropy accumulates. Eventually, the stem cell pool can't renew tissues. That's the hypothesis.»*
