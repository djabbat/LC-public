| Джаба | Они |

| Центриоль — **conditional entropy carrier**: в centrosome mode энтропия накапливается (polyE — компенсаторный ответ), в cilium mode — накопление прекращается | Микротрубочка — **orchestrated quantum computer**: коннективные белки (MAPs) «оркеструют» редукцию |

### Пересечение #3: HARDWARE/SOFTWARE РАЗЛИЧИЕ

| Джаба | Они |
|-------|-----|
| **Центриоль = hardware** (неремонтопригодна in situ, но заменима de novo) | **Микротрубочка = hardware сознания** (квантовый компьютер, не классический) |

## 3. КОНКРЕТНЫЕ МОЛЕКУЛЯРНЫЕ ТОЧКИ КОНТАКТА

### 3.1. Polyglutamylation — компенсаторный механизм, не источник энтропии
- Центриоль накапливает энтропию через ошибки репликации, окислительные повреждения, хронологический износ
- **PolyE — ответ клетки на эту энтропию:** TTLL-глутамилазы добавляют polyE как компенсаторную модификацию
- Добавление polyE (отрицательно заряженный глутамат) меняет электростатический потенциал тубулина
- Это **прямо меняет дипольный момент тубулинового димера** — именно то, что Hameroff использует для квантовых вычислений
- **Гипотеза для обсуждения:** компенсаторный polyE на центриолярном тубулине модулирует квантовые свойства микротрубочек?

### 3.2. sinc-MT pathway (Robichaud 2024) — stress-induced microtubules
- Стресс → de novo микротрубочки с необычным polyE → ARL13B-ARL3 → FBF1 transport → сенесценс
- KIFC3 knockout предотвращает сенесценс
- **Вопрос к Bandyopadhyay:** можно ли измерить изменение резонансных частот sinc-MT vs нормальных MT?

### 3.3. Цилия как антенна
- Jeffries (2019): невозможность реабсорбировать первичную цилию → сенесценс
- Hameroff: микротрубочки в цилии — антенны для квантовой информации?
- **Пересечение:** цилия = microtubule-based organelle, центриоль = её темплат

### 3.4. Четыре эволюционные линии (таблица Джабы)
- C. elegans элиминирует центриоли в соматических клетках
- Drosophila удаляет центриоли в оогенезе через Polo-киназу
- Планарии: стволовые клетки без центриолей
- Человек: PLK4↓ → потеря центриолей → p53-зависимая дифференцировка

> Природа использовала один и тот же трюк в четырёх независимых линиях: **убрать центриоль → изменить судьбу клетки.**
