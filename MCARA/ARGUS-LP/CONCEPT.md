## Концепт

ARGUS-LP — автономная роботизированная платформа для долгосрочного отслеживания клеточных линий (lineage tracking) с лазерной элиминацией клеток по заданным критериям. Ключевая технология для валидации CEDAR.

### Ключевая архитектура (v3)

- **Инвертированный DIY-микроскоп:** объектив снизу, чашка Петри неподвижна сверху
- **Водяная иммерсия:** 60×/1.2 Water + муфта (collar) + капиллярная подача 0.1 мл/ч — 24/7 без пересыхания
- **Герметичный ящик:** 40×30×30 см, CO₂ 5%, O₂ 2%, 37±0.3°C
- **Управление снаружи:** RasPi 5 + Hailo-8L + SSD 1 TB (не внутри — исключён перегрев и SD-карта)
- **AI-агент:** Mac M4 Pro 48GB + Qwen VL 72B (видит клетки, пишет код, принимает решения) — локально, без API
- **Самообучение:** LoRA еженедельно + RAG (Qdrant) + детекция аномалий
- **Защита от лазеров:** 4 уровня (фильтры OD6+, дихроик OD4+, механический затвор, notch-фильтры) + Class 3B
