## Архитектура системы

ARGUS-LP (AI-Resident Robotic Genealogical Ultra-surveillance for Lineage Purification) — автономная роботизированная платформа для долгосрочного отслеживания клеточных линий с лазерной элиминацией клеток по заданным критериям.

### Ключевые компоненты

| Компонент | Спецификация | Назначение |
|-----------|-------------|------------|
| **Микроскоп** | Инвертированный DIY, объектив 60×/1.2 Water | Визуализация клеточных делений |
| **Лазер** | 405 нм, Class 3B, 4 уровня защиты | Элиминация клеток-мишеней |
| **Камера** | sCMOS | Детекция делений |
| **Контроллер** | Raspberry Pi 5 + Hailo-8L (13 TOPS) | Real-time AI (<300 мс) |
| **AI-агент** | Mac M4 Pro 48GB + Qwen VL 72B (локально) | Принятие решений, vision |
| **Среда** | Герметичный ящик 40×30×30 см, CO₂ 5%, O₂ 2%, 37±0.3°C | Долгосрочная культура |
| **Хранение** | SSD 1 TB + LoRA еженедельно + RAG (Qdrant) | Данные + самообучение |

### 6 версий (поэтапная сборка)

| Версия | Бюджет | AI | Ключевая возможность |
|--------|:-----:|-----|---------------------|
| V1 | $2,045 | CPU RasPi 5 | PoC: поймать деление |
| V2 | $5,945 | CPU | + лазерная элиминация |
| V3 | $6,020 | Hailo-8L | + real-time AI (<300 мс) |
| V4 | $8,120 | Mac M4 Pro + Mixtral 8×7B | + AI-агент (локально) |
| V5 | $8,170 | M4 Pro + LoRA + RAG | + самообучение 24/7 |
| V6 | $8,170 | M4 Pro + Qwen VL 72B + OpenHands | Claude Code-уровень |

### Уровни защиты от лазера
1. Фильтры OD6+
2. Дихроик OD4+
3. Механический затвор
4. Notch-фильтры

### Программная архитектура
- Python (Raspberry Pi): управление микроскопом, захват изображений
- Rust (Mac): AI-агент, принятие решений, планирование экспериментов
- Qdrant: векторная база данных для RAG
- OpenHands: автономное программирование (V6)

## Связь с CEDAR

ARGUS-LP — экспериментальная платформа для валидации CEDAR:
- Отслеживание клеточных линий → проверка C1 (polyGlu ↔ деления)
- Лазерная элиминация → проверка C2 (асимметричное наследование центриолей)
- Долгосрочная съёмка → измерение D_critical
