# PROMPT.md — Natural-Language шаблоны для агента микроскопии (Claude Code /overnight)

> **Назначение:** шаблоны natural-language инструкций для агента, управляющего автоматизированным микроскопом в `/overnight` режиме. Паттерны адаптированы из SYNAPS-I (Argonne/DOE, agentic AI для микроскопии) и verified refs в `EVIDENCE.md` (секция «Agentic AI & foundation-model microscopy»). Мастер-анализ: `~/Desktop/Services/docs/AGENTIC_AI_EDGE_FINETUNING_ANALYSIS_2026-10-07.md`.
>
> **Дата:** 2026-10-07. Требует валидации 48h в Phase A Month 1 до полной автономии.

## Структура любого PROMPT (обязательный каркас)
1. **Цель эксперимента** (что доказать, какая гипотеза CEDAR).
2. **ROI-описание** (что искать, на что похожа цель — «старая» vs «новая» центриоль).
3. **Автономия** (`auto_allow` / `require_human_approval` — risk-tiered, паттерн SYNAPS-I).
4. **Параметры сбора** (каналы, экспозиция, интервал, температура/CO₂).
5. **Критерии останова** (когда считать миссию завершённой/провальной).
6. **Журналирование** (каждое решение → лог с номером строки PROMPT).

## Шаблон 1 — Aim M1: Feasibility / качество супервизии
```
ЦЕЛЬ: Проверить, что агент достигает ≥80% качества контроля обученного техника
      для рутинных протоколов (M1, THEORY.md) при <20% стоимости.
ГИПОТЕЗА: [гипотеза CEDAR Phase A]
ROI: делящиеся клетки [линия]; GFP-centrin метка «старой» центриоли.
СБОР: каналы [GFP, DIC]; экспозиция [50–500 мс]; интервал [≥30 мин];
      среда: 37°C / 5% CO₂ / 80–95% RH.
АВТОНОМИЯ:
  auto_allow: фокусировка, выбор поля, смена канала, оценка плотности,
              ROI-скан (паттерн SYNAPS-I: шаг → анализ → решение → уточнение).
  require_human_approval: смена протокола, длительная пауза, аномалия среды,
              всё, что угрожает образцу/оборудованию.
ОСТАНОВ: N часов без делящихся клеток → WARN; плотность < порога → STOP+алерт.
ЖУРНАЛ: decision_log.csv — timestamp, PROMPT#строка, действие, самооценка агента.
ВАЛИДАЦИЯ: первые 48h — параллельная оценка человеком (Cohen's kappa,
      первичная конечная точка).
```

## Шаблон 2 — Агентный ROI-поиск «старая vs новая центриоль» (паттерн SYNAPS-I)
```
ЦЕЛЬ: Автономно найти и зафиксировать клетки, где визуально различимы
      «старая» (GFP-centrin+) и «новая» (GFP-centrin−/слабая) центриоли
      перед и после цитокинеза.
РОЛИ АГЕНТА (адаптация AFM-MCP arXiv:2608.26198):
  Messenger  — natural language → проверенные команды сцены/камеры.
  Pilot      — оценка качества кадра (резкость, контраст, плотность);
               если плохо — корректирует параметры.
  Doctor     — диагностика артефактов (дрейф, расфокус, пузыри, блединг);
               применяет только пред-одобренные меры.
ПОИСК (пошагово, SYNAPS-I):
  1) собрать кадр → 2) сегментировать клетки (SAMJ в Fiji / SAM3-LoRA,
     см. EVIDENCE) → 3) определить ROI-кандидатов по морфологической
     неопределённости (паттерн AutoRASOR arXiv:2609.22411) →
  4) решить куда двигаться → 5) уточнить → 6) найти цель → 7) авто-свитч
     на высокое разрешение (паттерн SYNAPS-I).
АВТОНОМИЯ: поиск/съёмка — auto_allow; интерпретация «это та самая старая
  центриоль» — require_human_approval (консервативно, риск галлюцинации SAM3).
ОСТАНОВ: найдено K событий цитокинеза с обоими фенотипами; или 3 недели.
```

## Шаблон 3 — Долгосрочный скрининг (3-недельный contact-inhibition, CEDAR)
```
ЦЕЛЬ: 3-недельный таймлапс контактного торможения BJ-hTERT [Hayflick 1965,
      PMID 14315085] с оценкой накопления «старых» центриолей.
СБОР: интервал ≤2 ч (лимит быстрой динамики, EVIDENCE «Limitations»);
      фокус: ежедневный autofocus-пасс + фидуциальные маркеры
      (рекалибровка каждые 48h, mitigation дрейфа).
СРЕДА: 37°C±0.3 / 5%CO₂ / 80–95%RH; LED 50% max, экспозиция ≤500 мс
      (митигация фототоксичности/блединга).
АВТОНОМИЯ: рутинные решения auto_allow; стратегические —
  require_human_approval; ежедневный 8 AM человеческий визуальный чек
  (слепое пятно: контаминация, EVIDENCE).
ОСТАНОВ: контаминация → STOP+алерт (fail-safe shutdown); evaporation →
  WARN + автодоливка если доступна.
```

## Шаблон 4 — Аудит качества/сжатия моделей (если деплой на CPU/edge)
```
ЦЕЛЬ: Проверить, что сжатая сегментационная модель (Cellpose-SAM W8A16 /
      смешанный W4/W8) не теряет качество на НАШИХ модальностях.
МЕТОД (паттерн arXiv:2609.21038): модальность-стратифицированная оценка,
  а не single-number: 95% bootstrap-интервал среднего изменения от FP32
  ≥ −0.02 для каждой модальности; 0 катастрофических отказов.
ДЕЙСТВИЯ: если W8A16 ок → деплой; если нет → вернуться к FP32 (CPU-инференс).
```

## Шаблон 5 — Мониторинг среды и здоровья образца (WARN-слой)
```
ПЕРИОДИЧНОСТЬ: каждые 15 мин.
ПРОВЕРКИ: T, CO₂, RH; плотность клеток; признаки контаминации (WARN-флаг);
          статус стеpper-драйвера (дрейф).
ПОРОГИ: T ±0.5°C / CO₂ ±0.5% / RH 80–95% → WARN; выход за пределы → STOP.
ДЕЙСТВИЯ: все WARN журналируются; аномалия среды → уведомление человеку
          (Telegram/email), авто-fail-safe.
```

## Правила безопасности (обязательные, из EVIDENCE risk-matrix + SYNAPS-I)
- `auto_allow`-список узкий; всё остальное — `require_human_approval`.
- Каждое решение агента — в decision_log (для post-hoc аудита concordance).
- Никакой физической манипуляции образцом в Phase A (нет liquid handling).
- Если агент галлюцинирует ROI (сегментирует несуществующее) — повторный
  кадр + WARN, не принимать решение о съёмке без человека.
- Никогда не запускать автономный режим до прохождения 48h-валидации.
